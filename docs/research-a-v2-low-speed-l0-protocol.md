# 研究A v2-L0 — 低速打鍵の教師なし獲得・探索実験（実行前固定）

**状態：探索実験の事前固定。正式研究002の事前登録承認ではない。**

## 1. 研究上の問い

「単指でも打鍵できる比較的遅い速度」で、現在の学習方法が打鍵時刻と
押し直しを学習できるかを調べる。これができなければ、2指を使う
高速運指学習を始めても失敗の原因を切り分けにくい。

**ここでは左右交代率を成功条件にしない。**
低速ではA1（2指）が片側の指を好んで使っても問題ない。
指の使用率と物理KeyDown履歴は観測のためにのみ記録する。

## 2. 環境・比較条件

- **A0**：単指（右指を物理的に無効化）
- **A1**：左右2指を自由に操作
- Motor：既存の `personal_blue_switch_v0_1`、`same_hand=True`、
  制御10ms、物理1ms。身体定数の変更なし。
- 16打の等間隔時刻列。目標時刻に正解指を付与しない。
- 方策観測：次の目標までの**相対時刻**、目標間隔、
  2指の位置・速度・押下状態（8次元）。絶対時刻・正解キー・
  学習済み運指・将来の列の正解指は与えない。
- 4行動：`none, right, left, both`。
  物理的なKeyDownの発生時刻を判定器が使う。
- 報酬は元の`NoPositiveNearMissEnv`（R1）を変更せず使用。
  Hitは±20ms。失敗KeyDownに正の近傍報酬を出さない。
  指の使用比率・交代率の報酬は**なし**。
- PPOはA002-Pの実装を変更せず、ActorCritic（2×32）と
  `update_ppo`を使用。指の教師・BC・外部チェックポイントを使わない。

## 3. 学習条件（この文書後、実行前に固定）

- 学習列の間隔：**200ms、260ms**（各エピソード独立一様抽選）。
  既存001bでは指定した周期制御で単指の成功が観測されている。
  今回のRLにとって容易だという保証はない。
- 学習開始時刻：**0.78〜1.12秒**から独立一様抽選。
- 全エピソード：**256回/アーム・シード**。
- シード：**0、1**。2アーム × 2シード＝**4モデル**。
  A0とA1は同じ乱数種・重み初期化を使うが、重みを共有しない。
- 8エピソードごとにPPO 2epoch更新。
- `gamma=.99, clip=.2, lr=.0005, entropy_coef=.01, value_coef=.5`。
- 実行はCPU単一スレッド、Python 3.11、PyTorch 2.5.1+cpu。
- 学習予算と停止位置は**固定**。途中の評価を見て延長・早期停止しない。

## 4. 評価（学習には使用しない）

- 未学習の間隔：**210、240、250ms**。
- 開始時刻：**0.835、1.075、1.290秒**。
  3×3＝9個の評価ケース、各16目標。
- 評価タイミング：0、128、256エピソード終了時。
- 決定論的argmax評価：上記9ケースを各1回。
- 確率抽選評価：上記9ケースを各**4回**。
  シードは `320000 + 100*case_index + repetition`。
  各モデル・時点で同じシードを使用する。
- 原因追跡：各ケースでHit、Miss、Extra、物理KeyDownの左/右数、
  Hitしたキー列、実際のKeyDown時刻、命中時刻誤差、
  行動選択数、Entropyを記録する。
- A3（未学習の一様ランダム方策）をA0/A1両方の身体で
  同じ9ケース×4反復の確率抽選として評価する。
- A0とA1の全結果を残し、片方だけよいシードを抜き出さない。
- 各最終重み・モデルSHA256・全学習履歴・全評価JSONを保存する。

## 5. 評価の解釈

- **主指標**は確率抽選評価のHit率・Extra/目標数。
  学習中も確率抽選行動であり、argmaxだけで成功を宣言しない。
- **比較項目**は、A0/A1ごとの0→128→256の変化と、
  同条件A3との差。argmaxも別欄で全件報告する。
- **低速獲得の参考基準（予備研究用）**：
  最終256時点、A0・A1**両シードとも**、未使用条件の
  sampled評価でHit率 **90%以上**、
  Extra KeyDown/目標数 **5%以下**。
  これを満たさなければ「低速を正確に学習できた」は未達。
- 本判定に**左右交代率や左右均等性は一切用いない**。
- 低速の基礎獲得が未達でも、
  **物理的な単指不可能性やRL原理上の不可能性を主張しない**。
  単にこのMotor・PPO・報酬・予算では達成しなかったと記録する。
- 学習指導、報酬、行動空間、ネットワーク構造を途中で変更しない。
- 結果に基づく修正は**別の実験版**で固定した後に実行する。
