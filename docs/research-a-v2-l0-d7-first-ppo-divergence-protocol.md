# 研究A v2-L0-D7 — R1の最初に異なるPPO更新を逐次照合する（実行前固定）

**状態：実験コード・CI実行前の固定計画。正式研究002は未承認。** D5/D6の既知結果を踏まえた追試であり、盲検実験とは呼ばない。

## 問いと操作対象

D3はR1の4モデルを全32更新・最終重みまで完全再現したが、D5の独立した2実行ではR1 A0 seed0の最終重みが元R1と異なった。D6では32試行刻みの進捗で最初の差が128試行時点と判明した。**D5と同じR1 A0 seed0の学習経路を再実行し、各PPO更新で最初に数値が異なる箇所を特定できるか**を調べる。

比較するのは、同一R1学習条件の元R1の32更新ログと、D3の全更新時Actor勾配・物理KeyDown記録。今回の操作は**更新ごとの記録・照合・早期停止**のみで、学習・身体・報酬・PPOを変えない。D5と同じく元R1/R2/D3のartifactを読み、D3のTraceR1/Recorderと元train_modelを使う。R1 A0 seed0だけを実行する。

## 測定・照合と判定

1. 既存artifactのモデル識別子・D3のR1再現フラグ・元の32学習行・D3の32更新・元/D3最終チェックポイントSHAを検証。不一致なら学習前に停止。
2. 元の学習開始時評価（argmaxとsampledの全行）を完全一致で照合。異なれば学習を始めず、`initial_evaluation_diverged`とする。
3. 各8試行後、元のPPO更新をD3 Recorderで記録。各更新の**元R1学習行の全フィールド**、D3のActor勾配（2回・全要素）・損失・Hit/Extra・物理KeyDownイベント（押下開始、時刻、判定、優位度、行動確率変化を含む）を厳密比較する。各更新ごとに最初の差の場所と値を記録し、1つでも差があれば直ちに停止。許容誤差・結果後の基準変更は禁止。
4. 1〜16更新（最大128試行）の範囲で最初の差を特定できた場合は`first_update_divergence_identified`。最初の差が学習行・Actor勾配・物理イベントのどこに現れたかを区別する。因果原因までは主張しない。
5. 16更新まで全件一致なら`no_divergence_through_128`。D5の再現失敗を今回の環境では再現できなかったと報告し、D5の差が誤りだったとはしない。最終重みは検証していないため元R1の完全再現とは呼ばない。
6. 保存欠損・例外・記録数不一致は`invalid_diagnostic`として停止。失敗時の途中記録と例外を残す。R2の歴史的勾配・運指獲得・人間同等性・単指物理限界・正式研究002は認証しない。

最大16更新・128試行。最初の厳密不一致で早期停止。D3の全256試行を無意味に再実行しない。テスト、専用GitHub Actions、結果JSON、失敗ログを新規artifactに保存。最初に本計画を別ブランチにコミットし、その後にコード・CIを実装してDraft PRで隔離する。元PR #34・#37〜#49を変更せず、**自動マージとDraft解除を永久禁止**する。
