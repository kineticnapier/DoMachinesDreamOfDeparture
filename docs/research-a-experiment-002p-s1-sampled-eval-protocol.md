# 研究A002-P-S1：確率的評価と最大確率評価の比較（事前固定）

**状態：未実行の予備診断条件。正式002の事前登録ではない。**

## 問い

A002-PとR1では、確率分布のエントロピーが最大値 `ln(4)` に近いにもかかわらず、
決定論的な最大確率行動での評価では物理的KeyDownが片指側だけに
集中した。この偏りは「最大確率行動を選ぶ評価」の結果か。
学習時と同様に行動を確率から抽選した場合、両指による物理的KeyDownは
発生するのか、精度と余分な打鍵はどう変わるのか。

## 固定した資料とモデル

- 対象はR0（元の近傍報酬）とR1（近傍正報酬なし）の
  **既存8モデルすべて**（A0/A1 × seed0/1 × R0/R1）。
- **学習しない。** 元の実験[41300077879](https://github.com/kineticnapier/DoMachinesDreamOfDeparture/actions/runs/41300077879)
  のartifact `13080738533` に保存された **96エピソード終了時の最終重みのみ**を使う。
- `paired-results.json` でモデルごとの最終SHA-256を照合する。
- Motor定数・評価器・報酬・観測・ネットワークを**変更しない**。
- 学習中の行動割合を後から復元したと主張しない。

## 評価法

1. **argmax**：従来と同じ、確率最大の行動を常に選ぶ。
   各モデル9エピソード（3間隔×3開始時刻）を再実行し、
   元の`paired-results.json`の **各9行**と
   `hits / targets / extra_keydowns / physical_keydowns / matched_keys`
   を厳密照合。不一致なら比較妥当性を保留する。
2. **sampled**：同じ方策出力の4行動確率に従い、`torch.multinomial`
   で毎制御ステップ抽選する。独立な乱数生成器を各エピソードに設定し、
   全モデルで**同一の評価乱数の種列**を使う。
   `100000 + 100*評価組番号 + 反復番号` をそのまま乱数の種とする。
3. **sampledの反復数は各モデル・評価条件につき16**。
   3間隔 `105,115,125ms` × 3開始時刻
   `0.83,0.97,1.21s` × 16反復 = 144エピソード、
   **2304目標/モデル**。全8モデルについて行う。
   途中の結果を見て反復数を変えない。
4. 評価中に新たな学習・最良モデルの選定・報酬の変更はしない。
   評価時のみ`torch.no_grad`を用いる。

## 記録と判定

モデルごと、両評価法それぞれについて：
- Hit率、余分なKeyDown総数、完全命中エピソード数
- 実際に物理的に発生した左右KeyDown数
- **1エピソード中に両指の物理KeyDownが起きた割合**
- 物理KeyDown列の左右切替割合（分母が0なら`null`）
- Hitに割り当てられたキー列の左右切替割合（分母が0なら`null`）
- 行動指令の選択割合、平均Softmax確率・エントロピー
- 16回の反復全てについて、命中数/余分な打鍵/物理使用キーを記録

各モデルの`argmax`結果と`sampled`結果の分母が異なるため、
総命中数ではなく**Hit率とエピソード当たり余分なKeyDown**を比較する。
ペアのある反復番号はシード共有だけであり、異なる方策で行動列が
同じになることを保証しない。

**探索上の解釈基準（成功の改定ではない）**：
- sampledでA1の両指から物理KeyDownが生じた場合、
  「argmax評価の片指偏重は確率的評価では再現しない」と言える。
- それだけでは運指の自力獲得ではない。
  **高いHit率・低いExtra・Hit左右交代率**が同時に成立する必要がある。
- sampledでも片指のみなら「確率的評価でも両指を使えていない」。
- いずれも正式研究002の成功条件には影響を与えない。
- 評価エピソードを独立した人間とみなした信頼区間や一般化の主張をしない。
  学習シードは2件のみで、統計的な一般化はできない。
