# 研究A / 実験001b：定常連打能力の事前固定プロトコル v1

状態：**予備研究の条件固定。研究Aの本登録・身体能力認定ではない**。
この条件を結果を見た後に書き換えない。変更は別版・別の実行とする。

## 背景と仮説

先行001a（run 41287352794）は開始直後の反応遅れによって
単指が全条件不合格となった。事後の分析では単指180msで
最初の3打だけ失敗、2指80msでは最初の6打だけ失敗している。
これを見た**後で設計した予備実験**であり、完全に独立した検証ではない。

仮説：同じ2指身体モデルに同じ周期的な指令方式を与えたとき、
ウォームアップを別に記録すれば単指と2指の連打能力の差が現れる。

## 身体・判定器・計測環境

- `MotorEnv(same_hand=True, control_dt_s=0.010)`
- 物理1ms、既存 `personal_blue_switch_v0_1` を**無変更**使用。
- 人間の身体能力と等価だとは主張しない。
- 判定は単純な一対一のKeyDown時刻照合。窓は **±20ms**。
  ADOFAI本家判定器との同等性は主張しない。
- 左単指、右単指、2指交互の3アーム。交互運指を**測定器側で指定する**
  ことを許すが、Experiment002の学習器に渡してはならない。
- 対象は毎回等間隔の単純な入力列。学習や強化学習は実行しない。

## ウォームアップと本測定

- 一度Motorを初期化し、**3.0秒間**、同じ周期・同じ指令で打鍵を続ける。
- その後Motorをリセットせず、そのまま測定する。
- 最初の3秒の失敗・余分なKeyDownも**別欄に必ず記録**。
- 主要評価はその後の定常区間。短時間選択6秒、最終確認18秒。
- 選択用の最初の目標時刻は1.130秒。
- 最終確認は **1.137秒、1.273秒、1.419秒** の3条件で、
  実行ごとに新しいMotorから開始する。
- 最終確認の前半9秒と後半9秒も別々に報告する。
- ウォームアップ中も全押下・離鍵を同じ物理モデルで計算する。
  途中から物理状態を捏造して初期化してはいけない。

## 合格条件（各最終確認・3条件すべて）

- 定常区間の命中率 **95%以上**。
- 定常区間の余分なKeyDown **0**。
- 単指で使用禁止側のKeyDown **0**。
- 2指交互では、照合されたKeyDownの左右が想定の交互順に合致。
- 各9秒半区間でも95%以上を満たす。
- 測定した条件のうち、最短で合格した周期を**この周期指令候補集合で
  確認できた最短周期**と呼ぶ。最速の身体能力の証明とは呼ばない。
- 未到達・不合格、先行001aとの不一致も欠落させず記録する。

## 判定上の注意

- 最初の3秒を除くのは**本実験前に確定した採点規則**。先行001aの
  事後分析値を正式合格に書き換えるものではない。
- ターゲットとの照合は全期間で一対一とし、得点窓の境界にある入力を
  二重に数えない。
- 予測した正解時刻は研究001の測定器にだけ使用し、Studentへ与えない。
- この検証だけで単指の**物理的な不可能性は示せない**。
  より良い制御方法が存在する可能性を明記する。
- 001本登録、学習002の開始、身体モデル凍結は別判断とする。
